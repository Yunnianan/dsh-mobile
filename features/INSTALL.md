# 安装指南

从零开始把 DSH 装到手机上——不需要投屏，也不需要把电脑画面传到手机。

按顺序做即可：**Tailscale（不在同一 WiFi 时才需要）→ 装插件 → 装 APK → 配对**。

> 想快点上手？看 [快速开始](QUICKSTART.md)。本文是完整版，含原理与排错。

## 0. Tailscale 是什么、什么时候要装

**一句话**：Tailscale 是一个免费的个人虚拟局域网。装好之后，不管你在哪（4G/5G、别人家的 WiFi、公司网络），手机都能像在同一个局域网里一样连到你的电脑。

**什么时候需要**：

| 场景 | 需要 Tailscale？ |
|---|---|
| 手机和电脑在**同一个 WiFi** | 不需要，直接连 |
| 手机用流量、或在外面 | **需要** |

### 0.1 手机安装

1. 打开 App 的引导页，点「下载 Tailscale（官网）」，会打开 <https://tailscale.com/download>
   （也可以自己在浏览器输入这个地址，或在应用商店搜 Tailscale）。
2. 下载并安装 Android 版。
3. 打开 Tailscale，**用账号登录**（Google / Microsoft / GitHub / 邮箱都行）。
4. **把开关打开**——这一步最容易漏。只登录、不开开关是不通的。

### 0.2 电脑安装

1. 同一个网址下载 Windows 版并安装。
2. **用同一个账号登录**（必须和手机是同一个账号，否则两边不在一个网络里）。
3. 打开开关。

### 0.3 拿到地址

电脑装好后，Tailscale 会给它一个 `100.x.x.x` 的地址。手机浏览器访问 `http://100.x.x.x:19387` 能打开 DSH 就说明通了。

不知道确切地址也没关系：**桌面 DSH 左下角的配对面板会显示当前可用地址**，点「复制」就能拿来粘贴。

> 注意：Tailscale 地址在账号内可能被重新分配，以面板显示的为准。

## 1. 装插件（电脑）

插件是一个普通的 Node 包，**没有第三方依赖**，不需要 `npm install`。

**为什么要注意安装方式**：DSH 读取一个插件要三处同时成立，**漏掉任何一处都不会报错，插件只是静静地不挂载**（表现为左下角一直没有配对面板）：

1. profile 的 `package.json` → `dependencies` 里声明它
2. 同一个文件的 `dsh.profile.bundles` 数组里列出它的名字
3. `node_modules/dsh-mobile-public` 能解析到插件目录（目录联接）

下面的一键安装会把这三件事一次做完并检查结果。

### 1.1 一键安装（推荐）

1. 把插件目录放到一个**不会被临时清理**的位置，例如 `C:\Users\<你>\dsh-mobile-plugin`。
   不要放在"下载"里再引用它——那些目录会被清理工具删掉。

2. 在**插件目录**里执行：

   ```bash
   cd C:\Users\<你>\dsh-mobile-plugin
   node install.mjs --dry-run    # 先看会改什么，不动任何文件
   node install.mjs              # 正式安装
   ```

   正式执行后它会打印三行结果：

   ```
   dependencies  : updated            （或 already correct）
   bundles       : added dsh-mobile-public
   node_modules  : created
   ```

   装到别的位置：

   ```bash
   node install.mjs --profile "D:\其它profile目录"
   ```

   默认目标是 `%USERPROFILE%\.dsh\profiles\desktop`。

   脚本是**幂等**的：重复运行只会报 `already correct`。如果 `node_modules` 里已经有一个**同名的真实目录**，它会**拒绝覆盖**并提示你自己处理——那可能是别人的安装，删掉会丢文件。

3. **完全退出 DSH 再重新打开**。插件只在宿主启动时挂载，热加载不会重新载入插件。

4. 验证插件起来了：

   ```
   http://127.0.0.1:19387/m/api/status
   ```

   返回一段 JSON（含 `profile` / `tunnel` / `deviceCount`）就对了。

5. 确认网页服务监听局域网地址（**否则手机连不上**）：在
   `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml` 里，`webserver` 的 `host` 必须是
   `'0.0.0.0'`。默认是 `127.0.0.1`，那个只允许本机访问。改完重启 DSH 生效。

### 1.2 手工安装（脚本用不了时）

1. 同样先把插件目录放到不会被清理的位置（见上）。
2. 可选：先自检文件完整：

   ```bash
   cd plugin
   node selftest.mjs
   ```

   打出 `ALL CHECKS PASSED` 就没问题。

3. 打开 DSH 的桌面配置目录，编辑 `package.json`：

   ```
   %USERPROFILE%\.dsh\profiles\desktop\package.json
   ```

   **a)** 在 `dependencies` 里加一行（路径用正斜杠）：

   ```json
   "dsh-mobile-public": "link:C:/Users/<你的用户名>/dsh-mobile-plugin"
   ```

   值是 npm 的 `link:` 协议，指向磁盘目录，不是版本号。

   **b)** 在同一个文件的 `dsh` > `profile` > `bundles` 数组里加上插件名：

   ```json
   "bundles": [
     "@deepseek-ai/dsh-base",
     "@deepseek-ai/dsh-web-app",
     "dsh-mobile-public"
   ]
   ```

   **漏掉这一步插件不会挂载**，表现为左下角一直没有配对面板。

4. 建目录联接（Junction），让包名解析到磁盘目录：

   ```
   cmd /c mklink /J "%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-mobile-public" "C:\Users\<你的用户名>\dsh-mobile-plugin"
   ```

   `mklink` 是 cmd 的内部命令，PowerShell 里不能直接写，所以要 `cmd /c` 包一层。

5. 之后同样要**完全退出 DSH 再打开**，并按 1.1 的第 4、5 条验证。

> 手机访问必须用 **IP 地址**，不能用主机名：宿主只信任网卡上的 IPv4 字面量，用主机名会出现"网页能打开、但每次操作都 403"。

## 2. 装 APK（手机）

APK 在 [dist/](../dist) 目录里（也可从 [Releases](../../releases) 下载）。

1. 把 `dsh-mobile-*.apk` 传到手机（USB、网盘、聊天工具传文件都行）。
2. 在文件管理器里点它安装。
   - 小米 / HyperOS：如果被拦截，先到 设置 → 更多设置 → 开发者选项 → 打开「USB 安装」。
   - 这是自签名应用，会出现"未知来源"提示，允许即可。
3. **升级安装**：所有版本用同一张签名证书，直接覆盖安装即可，**配对状态保留**，不需要先卸载。

## 3. 第一次打开：引导 + 配对

### 3.1 首启引导（只出现一次）

第一次打开会自动显示引导，两步：

**第一屏 · Tailscale 安装说明** —— 讲清 Tailscale 是什么、什么时候需要、怎么装（同一账号 + 两边开关都要开）、装完怎么把地址填进来。

- 「下载 Tailscale（官网）」→ 打开官网
- 「我知道了，返回」→ 进入第二屏

**第二屏 · 怎么用 · 第一次连接** —— 4 步说明怎么配对。

- 「开始配对」→ 进入配对页
- 「看 Tailscale 安装说明」→ 回第一屏
- 「跳过引导」→ 直接进入配对页

引导走完后会被记住，**以后启动不再出现**，直接进配对页。

### 3.2 配对

两条路，选一条即可。

**方式一 · 扫码（推荐，最省事）**

电脑上，DSH 界面**左下角**有一个配对面板，里面是二维码。手机上点「扫码 / 配对链接」→ 扫这个二维码。二维码里已经带了一次性密钥，扫完自动配对，不用手抄任何东西。

**扫不了码？用相册里的图**：二维码是截图、或别人发给你的图片时，在扫码页点底部的「从相册选图」，选那张图就能识别——不用对着另一块屏幕拍。它会自动处理图片的旋转、缩放与清晰度，所以截图、拍照、压缩过的图都能读。

> 面板可以点「⇥」收成左下角的小标签，点一下再展开；点「刷新二维码」可以换一张新的。

**方式二 · 手输地址**

点「输入 IP 地址」→ 填地址 → 「下一步：配对设置」→ 补一次性密钥 → 「连接」。

同一 WiFi 下可以点「自动发现」，它会自己找到电脑并填好地址。不想手打的话，在面板点「复制链接」发到手机，然后在地址页点「从剪贴板填入」。

要填的东西（两种方式一样）：

| 字段 | 内容 |
|---|---|
| 主地址 | `http://<电脑的 Tailscale IP>:19387`（任何网络都能用） |
| 备用地址 | `http://<电脑的内网 IP>:19387`（同一 WiFi 时更快） |
| 一次性密钥 | 桌面面板上「一次性配对密钥」那一栏 |

配对成功后会自动进入 DSH 界面。

## 4. 日常使用

- **打开即用**：配对之后每次打开都会直接进界面，不用再扫。
- **顶部栏**：显示当前地址；有前进 / 后退；「返回设置」回到配置页。顶栏会在你向下滚动时自动收起，向上滑回来。
- **切回应用不重新下载**：页面保留，回来就能接着用。
- **设置页**（顶部栏的「返回设置」）里可以调：字号（小 / 标准 / 大）、主题（跟随系统 / 浅色 / 深色）、全屏沉浸、顶栏滚动动画开关、清除缓存。
- 文本可以正常长按选择、复制粘贴。
- 输入框、文件上传（选图片/文件）都在 WebView 内正常工作。

## 5. 常见问题

**手机显示「连接失败」**

1. 电脑上 DSH 是否正在运行；
2. 插件是否装好（见第 1 步第 4 条）；
3. 手机和电脑是否在同一 WiFi；不在的话，手机上 Tailscale 是否已连接（**只是登录不够，要把开关打开**）。

**网页能打开，但每次操作都失败（403）**

地址用了主机名。宿主只信任网卡上的 IPv4 字面量，必须用 IP 地址（如 `http://192.168.1.5:19387`），不能用计算机名。

**插件装了，但左下角没有配对面板**

DSH 读取插件要三处同时成立，漏一处**不会报错**、只是不挂载。依次核对：

1. profile 的 `package.json` → `dependencies` 里有 `dsh-mobile-public`
2. 同一文件的 `dsh.profile.bundles` 里有 `dsh-mobile-public` ← **最常漏**
3. `node_modules\dsh-mobile-public` 存在，且能解析到插件目录
4. 装完有没有**完全退出 DSH 再打开**（插件只在启动时挂载）

最快的检查办法：重跑一次 `node install.mjs`，它会把这三处补齐并报告结果。

**配对链接提示"无效或已过期"**

一次性令牌只能用一次。到桌面面板点「刷新二维码」换一张新的再扫。

**想关掉局域网可见**

把 `cordis.patch.yml` 里 `webserver` 的 `host` 改回 `'127.0.0.1'` 并重启 DSH。（这样手机就连不上了，只适合临时关闭。）

**地址怎么选（实测速度）**

| 地址 | 速度 | 适用 |
|---|---|---|
| 内网 IP | 约 3.2 MB/s | 同一 WiFi 下最快 |
| Tailscale | 约 2.3 MB/s | 任何网络可用 |
| 公网隧道 | 14–27 KB/s | 最慢，别当主地址 |

**安全提醒**

配对链接就是完整控制凭据，谁拿到谁能进你的 DSH。不要公开贴出来，二维码截图同理。

## 6. 可选：自检插件

不需要联网，也不动你真实的配对记录：

```bash
cd plugin
node selftest.mjs            # 配对存储、两种隧道提供方
node image-decode-test.cjs   # 手机端二维码图片解码（4 旋转 × 2 二值化 × 各种图像条件）
node integration.mjs         # 真实 HTTP 服务、路由、重定向
node origin-check.mjs        # 请求来源判定（内网请求留在内网）
node widget-edge-test.cjs    # 配对面板的贴边行为与明暗
node panel-geometry-test.cjs # 面板在 7 种屏幕尺寸下的位置
node diag-selfcheck.cjs      # 手机端诊断脚本的自检
```

量测工具（改面板几何前先看数，再改代码）：

```bash
node geometry-probe.cjs --matrix   # 打印 7 种屏幕下的位置矩阵
node flow-probe.cjs                # 按操作顺序逐步打印坐标
```

## 附录 A · 重新查看引导

引导只在首次启动出现。想再看一遍：

```bash
adb shell am start -a android.intent.action.VIEW -d 'dshmobile://onboard'
```

没有 adb 的话：卸载后重装也会再次显示引导。

其他命令：

```bash
adb shell am start -a android.intent.action.VIEW -d 'dshmobile://clearcache'
# 清缓存（不会清除配对状态）

adb shell am start -a android.intent.action.VIEW -d 'dshmobile://diag'
# 把当前页面的诊断信息打进日志（排查问题时用）
```

## 附录 B · 清除缓存

设置页有「清除缓存」按钮。清缓存**不会**清除配对状态，不用重新扫码；它只清网页缓存，下次打开会重新下载一次页面资源。

APK 每次启动也会做缓存维护：超过上限自动裁剪，升级后清掉旧版本资源。
